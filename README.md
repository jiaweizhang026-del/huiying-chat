# 回应 · AI 陪伴聊天 Demo

可直接在 **Codex / CodeBuddy / VS Code / 终端** 运行和继续开发的本地源码。没有 Coze、云端沙盒或专属插件依赖。原始设计资源已下载到 `public/assets`，不依赖 Figma 临时链接。

## 运行

需要 Node.js 20.19+（建议 22 LTS）与 npm。在本目录打开终端：

```bash
npm install
npm run dev
```

打开 **http://localhost:5178**。电脑显示居中的手机尺寸预览，可以切换 375 / 402 / 430px；手机宽度的浏览器铺满屏幕。前端使用 Vite + React Fast Refresh，修改 JSX/CSS 后自动更新。修改服务端代码或 `.env` 后需要重启 `npm run dev`。

端口 5173 已被当前电脑的 CodeBuddy 使用，因此默认选 5178。若冲突，在 `.env` 设置 `PORT=5180` 等空闲端口。默认仅监听 127.0.0.1，不公开到网络。电脑浏览器缩小时会自动缩短预览高度，402×874 设计比例在足够高的窗口里完整显示。

## 在 CodeBuddy 继续

1. 复制或打开整个项目文件夹，不要只复制 `src`。保留 `package.json`、`package-lock.json`、`server.mjs`、`server/`、`shared/`、`vite.config.js`、`index.html`、`public`、`src` 和文档。
2. 无需复制 `node_modules`、`dist`、`test-results`、`.git`，新机器重新 `npm install`。
3. 让 CodeBuddy AI **先读 `AGENTS.md`**，然后说明你想修改的页面。
4. 在 CodeBuddy 终端运行 `npm run dev`，浏览器打开上面的地址；每次修改会实时反映在预览里。
5. 可用提示：『先阅读 AGENTS.md，保持 Figma 原有灰白聊天视觉，修改 src/App.jsx 中的聊天交互，运行 npm run build 和相关测试，不切换云端平台。』
6. 要迁移自己的聊天和日常，停止服务后额外复制 `.local-data/state.json`；密钥在新机器单独配置 `.env`。这两项含敏感信息，不上传公开仓库。

## DeepSeek

本机已经通过 `.env` 配置真实 DeepSeek，并实际验证了聊天、回复建议和记忆生成。新机器没有配置密钥时才会进入明确标注的**演示模式**；本地规则回复不冒充 AI。

新机器将 `.env.example` **复制为 `.env`**，填写（不要覆盖已有的有效配置）：

```dotenv
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_MODEL=deepseek-flash
PORT=5178
HOST=127.0.0.1
```

重启服务，然后在「我的 → AI 连接」刷新状态。`待验证` 不等于已成功调用；发送一次消息成功后才显示已连接。服务重启后会重新验证。API 使用 `https://api.deepseek.com/chat/completions`。模型名可根据账户支持情况修改。调用失败会在消息旁显示重试，**不会偷偷降级为演示回复**。

密钥只在 Node 服务读取，不使用 `VITE_` 环境变量，不存入 localStorage，不提交 `.env`。API 会发送当前角色最近20条文字消息和最多8条非示例记忆；不会上传图片。正式使用请在 DeepSeek 控制台轮换曾粘贴在聊天中的密钥，再修改本地 `.env` 重启。

## 本地数据闭环

### 新版社区与 Hi

- 第三个 Tab 改为「社区」：朋友圈与广场独立浏览、发布、点赞、评论。旧动态默认属于朋友圈，不会被公开；朋友圈仅包含自己与已添加的AI好友。新评论弹窗沿用 Figma 第14页，提交等待磁盘保存，失败可重试且不会重复评论。
- 发现右上角 Hi 打开人物星球；22个可点选角色从星光放大、虚化进入标签，再到对应人物资料。支持取消、跳过和减少动态效果。新人物可以添加好友、聊天、查看记录和记忆。
- 星球根据本地聊天兴趣/非示例记忆/动态/点赞，对预设角色做规则匹配；**尚非大模型动态生成人物**。对外也不要把预设人设称为真实用户。
- 广场是本地可交互预览，其他用户回复/热度标为示例。尚无公网多人账号和实时社区后端。朋友圈/广场分栏是本地产品逻辑，不是可直接上公网的权限隔离。
- 首页原有光效层保留，入场光晕改为更慢、更低对比的扩散，避免硬环和骤然消失。

`npm run test:community` 验证以上流程（独立5188，不调用付费API；不要和UI/HMR测试同时运行）。

### 保存机制

前端通过 `GET /api/state` 加载，`PUT /api/state` 保存；后端写入项目下 `.local-data/state.json`（可用 `DATA_FILE` 指定位置）。采用临时文件 + 原子替换，并通过 revision 阻止旧窗口覆盖新数据。无需额外安装数据库。

- 发送前先保存用户消息；AI 回复、记忆、草稿、设置、动态、评论与点赞自动落盘。动态发布成功提示会等待写入成功。
- 浏览器只保留缓存与失败备份，不是唯一数据源；刷新、重启后端或更换同一电脑浏览器后仍可读取。旧版浏览器数据在后端首次为空时自动迁移。
- 保存失败显示横幅，可重试和导出备份；不会把磁盘保存失败伪装成发布成功。多窗口冲突时先导出再刷新，刷新会保留冲突备份，采用后端最新数据。
- 单机单用户文件存储，单次快照上限24MB。图片在前端压缩后以数据URL保存，不适合大量相册。运行中的 AI 请求尚未完成时关闭浏览器，不能保证生成结果恢复；离开页面会提示。
- 迁移或备份完整数据时先停止服务再复制 `.local-data/state.json`。不要手动改 revision；「我的」也提供 JSON 导出。

## 产品边界

- 微信按钮是体验登录，**不是真实微信 OAuth**。
- AI 角色均为虚构人物。「TA 在想」是可展示的文学旁白，不是模型内部思维链。
- 示例回忆和动态是演示数据，不是用户真实经历；实际记忆还需要人工核对。
- 数据存本机后端磁盘，没有账号系统、跨设备云同步、端到端加密或生产权限系统。删除 `.local-data` 会丢失后端数据；建议定期备份。
- 图片仅本机展示，不做图像理解；Web Speech 可能由浏览器厂商处理语音，不受本地服务控制。
- 当前是可运行的本地 MVP，未发布公网。不要直接将服务暴露到公网；正式上线还需账号鉴权、HTTPS、用户数据隔离、生产数据库/图片存储、费用限额和安全审查。

## 构建 / 测试

```bash
npm run build
npm start
```

开发与生产服务不可同时占用同一端口。先停止开发服务再 `npm start`。

在服务已经启动时运行 API 测试：

```bash
npm test
```

UI 测试（独立临时浏览器，不使用个人浏览器账号）：

```bash
npx playwright install chromium
npm run test:ui
```

macOS 已安装 Chrome 时也可不下载测试浏览器：

```bash
PLAYWRIGHT_CHROME_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npm run test:ui
```

截图存于 `test-results/`。`test:ui` 和 `test:hmr` 自动在5188启动独立服务，使用临时数据目录且强制无密钥，不花费 API 额度，也不修改自己的聊天数据；两项不要同时运行。

`npm run test:live` **会实际调用付费 API（正常2次）**，仅在需要验证真实连接时运行。它在5189使用独立数据目录，验证聊天、建议、记忆、带图动态及新浏览器恢复。浏览器安装要求同上。不要同时运行多个相同测试。

`npm run test:hmr` 验证 CSS/React 实时更新后聊天页面和草稿保留（浏览器安装要求相同）。`npm run format` 格式化源码。实际验收情况见 `TEST_REPORT.md`。

构建后 `npm run test:production` 会在5190验证生产服务、真实进程重启后的磁盘恢复、敏感文件访问保护及前端无密钥；无API费用。
